# Atalhos+\n\nApp web de atalhos rápidos, notas locais e leitura de ficheiros de texto.\n\n## Funcionalidades\n- Pesquisa instantânea dos atalhos.\n- Criar atalhos personalizados.\n- Criar notas guardadas neste navegador.\n- Abrir sites e tentar abrir o Free Fire instalado.\n- Ler ficheiros `.txt` localmente sem executar o conteúdo.\n\nOs dados ficam no armazenamento local do navegador. Os atalhos personalizados são descrições e não executam código nem alteram aplicações de terceiros.\n\nO projeto ainda não está publicado; podes testar e ajustar antes de publicar.\n
