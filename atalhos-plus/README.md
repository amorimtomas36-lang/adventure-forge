# Atalhos+

Uma pequena app web em português para organizar atalhos rápidos.

## Como abrir
Abre `index.html` no navegador ou publica a pasta `atalhos-plus` num alojamento estático.

## Funcionalidades
- Atalhos de exemplo e criação de cartões personalizados.
- Pesquisa de atalhos.
- Abrir e visualizar ficheiros .txt sem executar scripts.
- Atalho que tenta abrir o Free Fire através do mecanismo normal do Android; depende do navegador, do Android e de o jogo estar instalado.

## Limitações
- É uma app web, não um APK Android nativo.
- Não altera o jogo e não inclui cheats, aimlock ou bypass.
- Atalhos personalizados são cartões informativos e não executam automaticamente ações arbitrárias.
- Dados guardados no armazenamento local do navegador podem não ser partilhados entre navegadores/dispositivos.

Esta app está na pasta `atalhos-plus/` para não substituir os ficheiros do projeto RPG existente.
